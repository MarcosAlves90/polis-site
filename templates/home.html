ESCOLHA O SEU CENÁRIO

IA na web ou na sua máquina?

A diferença depende de onde estão o código e a validação, não apenas da interface do chat. Em ambos os caminhos há contrato, prova exigida e gates.

01 / AGENTE LOCAL

Agente de IA no seu computador

O agente tem acesso ao repositório e executa a CLI no mesmo checkout que está editando. Após bloquear o contrato, produzir a prova necessária e implementar, valide a alteração localmente.

polis workspace validate

Sem arquivo de entrega .polis. Um relatório de checkpoint externo é opcional e não é um pacote.

Ver validação local →
02 / CHATBOT OU IA NA WEB

IA na web com entrega para outra máquina

Se a mudança precisa chegar a outro checkout, um produtor com acesso real ao código, ao Git e à CLI executa o POLIS. Uma conversa sem essas ferramentas não cria nem verifica pacotes.

polis build → verify → preflight → apply

Com arquivo de entrega .polis, criado fora do repositório. O consumidor verifica e só aplica após autorização.

Ver entrega remota →

Arquivo .polis ≠ diretório .polis/ mudanca.polis é um pacote transportável gerado por polis build. Já .polis/ é um diretório de configuração do projeto: pode conter .polis/policy.json, .polis/policy-provenance.json e evidências em .polis/artifacts/. Também é possível usar uma política JSON externa com --policy. Ter o diretório não exige gerar um pacote, e novos pacotes nunca ficam retidos nele.

PRIMEIROS PASSOS

Seu terminal.
Seu controle.

Comece instalando a CLI. O comando doctor avalia o ambiente; init prepara a política para seu repositório; plan mostra como a validação será executada a partir da política explicitada.

Guia completo de instalação →
Instalação recomendada
# Requer Go 1.23+ e Git
go install github.com/MarcosAlves90/polis/v6/cmd/polis@latest

# Verifique a instalação
polis doctor

# Explore sua configuração de validação
# Execute na raiz de um repositório Git com módulo Go
# Diretório temporário fora do repositório
POLIS_OUTSIDE="${POLIS_OUTSIDE:-$(mktemp -d)}"
mkdir -p "$POLIS_OUTSIDE"
polis init --repo . --profile auto --dry-run > "$POLIS_OUTSIDE/policy.json"
polis doctor --repo . --policy "$POLIS_OUTSIDE/policy.json"
polis plan --repo . --policy "$POLIS_OUTSIDE/policy.json"
