PRINCÍPIOS

Mais do que executar testes.
Comprovar o caminho.

O POLIS liga requisitos, provas de desenvolvimento, políticas de validação e uma mudança de código identificável.

01 / ESCOPO

Contratos antes de código

Uma mudança nasce com requisitos, critérios de aceite, limites de arquivos e provas definidas.

02 / EVIDÊNCIAS

Validação reproduzível

Gates, provas Red/Green, identidade das entradas e resultados explícitos: PASS, FAIL ou BLOCKED.

Aplicação controlada

PRIMEIROS PASSOS

Seu terminal.
Seu controle.

Comece instalando a CLI. O comando doctor avalia o ambiente; init prepara a política para seu repositório; plan mostra como a validação será executada a partir da política explicitada.

Guia completo de instalação →
Instalação recomendada
# Requer Go 1.23+ e Git
go install github.com/MarcosAlves90/polis/v6/cmd/polis@latest

# Verifique a instalação
polis doctor

# Explore sua configuração de validação
# Execute na raiz de um repositório Git com módulo Go
# Diretório temporário fora do repositório
POLIS_OUTSIDE="${POLIS_OUTSIDE:-$(mktemp -d)}"
mkdir -p "$POLIS_OUTSIDE"
polis init --repo . --profile auto --dry-run > "$POLIS_OUTSIDE/policy.json"
polis doctor --repo . --policy "$POLIS_OUTSIDE/policy.json"
polis plan --repo . --policy "$POLIS_OUTSIDE/policy.json"
