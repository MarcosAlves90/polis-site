CHOOSE YOUR WORKFLOW

Web AI or AI on your computer?

The deciding factor is where the code and validation run, not just the chat interface. Both workflows require a contract, appropriate proof, and gates.

01 / LOCAL AGENT

AI agent running on your computer

The agent can access the repository and run the CLI in the checkout it edits. After locking the contract, collecting required proof, and implementing the change, validate that workspace.

polis workspace validate

No delivery .polis file. An optional external checkpoint report is not a package.

Local validation guide →
02 / WEB CHATBOT OR AI

Web AI delivering to another machine

For delivery to another checkout, a producer must actually access the source, Git, and POLIS CLI. A chat-only conversation cannot build or verify a package.

polis build → verify → preflight → apply

A transferable .polis file is built outside the repository. The consumer verifies it and applies only with authorization.

Remote delivery guide →

.polis file ≠ .polis/ directory change.polis is a transferable package produced by polis build. The .polis/ directory holds project configuration such as .polis/policy.json, .polis/policy-provenance.json, and optional evidence under .polis/artifacts/. A separate JSON policy can also be supplied with --policy. This directory does not mean a package was built, and new packages are never retained there.

GETTING STARTED

Your terminal.
Your control.

Install the CLI to begin. doctor checks your environment; init generates project policy; plan previews validation from the explicitly supplied policy.

Full installation guide →
Recommended installation
# Requires Go 1.23+ and Git
go install github.com/MarcosAlves90/polis/v6/cmd/polis@latest

# Verify installation
polis doctor

# Explore your validation configuration
# Run at the root of a Git repository with a Go module
# Temporary directory outside the repository
POLIS_OUTSIDE="${POLIS_OUTSIDE:-$(mktemp -d)}"
mkdir -p "$POLIS_OUTSIDE"
polis init --repo . --profile auto --dry-run > "$POLIS_OUTSIDE/policy.json"
polis doctor --repo . --policy "$POLIS_OUTSIDE/policy.json"
polis plan --repo . --policy "$POLIS_OUTSIDE/policy.json"
