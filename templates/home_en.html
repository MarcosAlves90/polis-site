GETTING STARTED

Your terminal.
Your control.

Install the CLI to begin. doctor checks your environment; init generates project policy; plan previews validation from the explicitly supplied policy.

Full installation guide →
Recommended installation
# Requires Go 1.23+ and Git
go install github.com/MarcosAlves90/polis/v6/cmd/polis@latest

# Verify installation
polis doctor

# Explore your validation configuration
# Run at the root of a Git repository with a Go module
# Temporary directory outside the repository
POLIS_OUTSIDE="${POLIS_OUTSIDE:-$(mktemp -d)}"
mkdir -p "$POLIS_OUTSIDE"
polis init --repo . --profile auto --dry-run > "$POLIS_OUTSIDE/policy.json"
polis doctor --repo . --policy "$POLIS_OUTSIDE/policy.json"
polis plan --repo . --policy "$POLIS_OUTSIDE/policy.json"
